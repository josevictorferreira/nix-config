## Key Implementation Details

### Flake Structure
```nix
{
  inputs = {
    # ... existing inputs ...
    flake-parts.url = "github:hercules-ci/flake-parts";
    import-tree.url = "github:vic/import-tree";
  };

  outputs = inputs@{ self, flake-parts, ... }:
    flake-parts.lib.mkFlake { inherit inputs; } {
      systems = [ "x86_64-linux" "aarch64-darwin" ];
      
      imports = [
        (inputs.import-tree ./modules/flake)
      ];
      
      perSystem = { system, ... }: {
        formatter = pkgs.nixpkgs-fmt;
      };
      
      flake = {
        # nixosConfigurations, darwinConfigurations, templates, lib
      };
    };
}
```

### Import-Tree Integration
- `import-tree` is configured to import from `./modules/flake`
- Paths containing `/_` are automatically ignored by import-tree
- Legacy modules remain in `modules/legacy/_/` and are imported explicitly
- This prevents accidental double-import of NixOS/Darwin modules as flake-parts modules
