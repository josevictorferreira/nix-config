## Lessons Learned

1. **pkgs.writeTextDir vs pkgs.writeTextFile**: `symlinkJoin` requires directories, not files
2. **pkgs.formats.ini limitation**: Doesn't support Booleans - need custom generator
3. **Text field type**: Must be string, not derivation - use `builtins.readFile` for format generators
4. **items path format**: Use full path including `.config/` prefix, not `xdg.config` shortcut
