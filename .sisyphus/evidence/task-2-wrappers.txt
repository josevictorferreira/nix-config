## Architecture
- Follows users.nix dendritic pattern: shared option definition via `mkWrappersOption`, shared logic via `mkWrappersConfig { isDarwin }` 
- `flake.modules.nixos.wrappers` = mkWrappersConfig { isDarwin = false; }
- `flake.modules.darwin.wrappers` = mkWrappersConfig { isDarwin = true; }
- Platform detection: hardcoded `isDarwin` parameter per platform (eliminates `system` specialArg dependency for branching)
- `inputs.lib.generators.toFileFormatStr` preserved via `inputs` module arg (from specialArgs)

## Key Design Decisions
1. Used `isDarwin` as closure parameter instead of `system` specialArg — avoids the infinite recursion concern noted in legacy code, and is cleaner since we have separate platform modules
2. All wrapper functionality preserved: script generation, config materialization, platform-specific home paths, activation scripts, atomic swap, preserve files, postInstall
3. NixOS activation: per-user named scripts with supportsDryActivation
4. Darwin activation: postActivation.text concatenation
