## Key Discovery: pkgs.stdenv.isDarwin Infinite Recursion
Using pkgs.stdenv.isDarwin causes infinite recursion when:
1. Used in `imports` blocks (evaluated before config/pkgs available)
2. Used in top-level `lib.optionalAttrs` in config (eager eval of condition requires pkgs → config._module.args → config → cycle)

Safe to use only inside mkIf-guarded config blocks where pkgs is already resolved.
