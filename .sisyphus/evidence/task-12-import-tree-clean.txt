# Task 12: Remove remaining legacy compatibility wiring
# Date: 2026-02-21

## Changes Made

### flake.nix - Removed dead code:
- `systems` attrset (macos entry, never referenced)
- `mkPkgs` function (only used by dead `lib` output)
- `specialArgsFor` function (never called; hosts define own specialArgs)
- `forAllSystems` helper (only used by dead `lib` output)
- `flake.lib` output (self.lib never referenced anywhere)
- Stale comments referencing "nixosModule/darwinModule below"

### modules/aspects/core-jvf.nix - Added core/options.nix import:
- Both nixos and darwin module sets now import ../core/options.nix
- Hosts no longer need explicit ../../modules/core/options.nix

### modules/hosts/nixos-desktop.nix - Removed explicit import:
- Removed ../../modules/core/options.nix from modules list
- All NixOS modules now come through aspects only

### modules/hosts/macos-macbook.nix - Removed explicit import:
- Removed ../../modules/core/options.nix from modules list
- Only remaining non-aspect module: { nixpkgs.hostPlatform = system; } (inline config, not a module file)

## Remaining Non-Aspect Imports (by design)
- hosts/*/config.nix: Host-specific configs (last in list for override)
- { nixpkgs.hostPlatform = system; }: Inline platform identity (darwin only)
- specialArgs in each host: Compatibility bridge for legacy modules
